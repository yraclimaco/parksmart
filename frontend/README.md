# Frontend

The proposed backend connection format, JSON fixtures, local CORS origins, and
team review checklist are in [the backend guide](../docs/backend.md). Start the
API with `python -m uvicorn src.api.main:app --reload` from the repository root.
The API currently serves fictional sample locations and no recommendations.

This folder is for the UI/UX portion of the project. Typical contents may include:

- React, Vue, or plain HTML/CSS/JS code
- static assets for dashboards or visualizations
- frontend build configuration
- a README describing how to run and deploy the web interface
